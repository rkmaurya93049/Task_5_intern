# Heart Disease Classification — Internship Task 5

A supervised machine-learning project using a heart-disease dataset to practice classification, exploratory analysis and model evaluation.

## Objective

This task develops a structured classification workflow for tabular health data, with emphasis on understanding input features, preparing the dataset and evaluating predictive models.

## Repository Contents

```text
Task_5_intern/
├── heart.csv             # Heart-disease dataset
├── task-inter-5.ipynb    # Main analysis/modeling notebook
└── README.md
```

## Skills Demonstrated

- Tabular data exploration
- Classification preprocessing
- Feature/target preparation
- Model training
- Prediction and evaluation
- Jupyter Notebook workflow

## Getting Started

```bash
python -m venv .venv
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
jupyter notebook task-inter-5.ipynb
```

## Responsible Use

This is an educational ML exercise and **not a medical diagnostic tool**. Model outputs from this repository should not be used for healthcare decisions.

## Project Type

**Internship / learning project.** The repository demonstrates classification practice rather than a production clinical system.
